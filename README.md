# FisioTrack — Sistema de Gestão de Clínica de Fisioterapia

Sistema moderno e seguro para o gerenciamento de fichas de avaliação e prontuários fisioterapêuticos.

⚠️ **Projeto em Desenvolvimento**

O sistema está sendo construído com foco em:
- **Segurança de Dados:** Armazenamento local criptografado (AES-256) via SQLCipher.
- **Portabilidade:** Desenvolvido em C++20 para alto desempenho e compatibilidade cross-platform.
- **Interface Intuitiva:** Frontend em React para agilizar o atendimento clínico.
- **Backup:** Suporte a backup criptografado em nuvem.

## Estrutura do Projeto
- `backend/`: API e lógica de banco de dados em C++.
- `frontend/`: Interface de usuário em React.
- `docs/`: Documentação e planos de implementação.
